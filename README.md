### 🚀 Featured Engineering Projects

#### 1. [Transformer Inference Profiler & Memory Telemetry Suite](https://github.com/Pratyush-kya/transformer-inference-profiler)
* High-resolution mechanistic telemetry profiler for autoregressive transformer decoding.
* Intercepts logits, calculates instantaneous **Shannon entropy**, candidate competition margins, and analytical KV-cache byte footprints ($2 \cdot B \cdot S \cdot L \cdot N_{\text{kv}} \cdot d_{\text{head}} \cdot b$).
* Pure in-RAM zero-disk architecture utilizing `/dev/shm` tmpfs circular buffers & SQLite in-memory tables (0.00 MB/s disk write rate).
* 29/29 PyTest test suite, 60 FPS Plotly Dash visual interface, and custom MCP LibreOffice presentation generator.

#### 2. [Resumint — Client-Side ATS Resume Builder](https://resumint-eta.vercel.app)
* Zero-cost, client-side resume builder and ATS score checker built with Next.js 16, React 19, and Tailwind v4.
* In-browser PDF extraction (`pdfjs-dist`) with real-time semantic keyword matching, zero server latency, and complete user data privacy.

#### 3. [Arogya-Relay — Healthcare Emergency Platform](https://arogya-relay.vercel.app)
* Emergency patient support and ambulance dispatch platform with live telemetry and location routing.
* Backed by active Supabase PostgreSQL 17 database instances with automated incident state tracking.
